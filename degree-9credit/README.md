# AI데이터센터운영 디그리 — 3과목 9학점 집중형

> **"AI데이터센터를 이해하고, 운영하고, 자동화한다 — 세 과목으로."**
>
> 21학점 정규 디그리([상위 폴더](../README.md))의 **운영 집중 압축판**이다.
> 보안관제는 학과의 다른 과목에서 충분히 다루므로 이 버전에서는 제외하고,
> **AI데이터센터 '운영' 그 자체**에 집중한다.

---

## 1. 이 버전의 설계 원칙

- **운영에 집중.** 데이터센터 운영자가 반드시 갖춰야 할 세 축 — 시설 관제,
  AI 서비스 운영, 운영 자동화 — 을 각각 온전히 다룬다.
- **보안 제외.** 보안관제(SOC·공방전)는 학과 내 타 과목에서 비중 있게 다루므로,
  이 디그리에서는 "시설 장애로부터 가용성을 지키는 운영"에 힘을 싣는다.
  (시설 경보가 SIEM으로 흐르는 접점만 과목 2에서 한 차시로 소개.)
- **LLM은 '만들기'에서 '이해하기'로.** LLM을 밑바닥부터 구축하는 전체 과정(정규판 ②)
  대신, **운영자가 워크로드를 이해하는 데 필요한 만큼**의 LLM 리터러시로 압축해
  과목 1에 편입한다.
- **하나의 세계관 유지.** 세 과목 모두 가상기업 kt66의 같은 데이터센터를 무대로 한다.

## 2. 세 과목

```
  [과목 1] 시스템 이해        [과목 2] 통합 운영         [과목 3] 자동화·통합
  ┌──────────────────┐    ┌──────────────────┐    ┌──────────────────┐
  │ 건물과 워크로드를    │──▶│ 시설을 관제하고     │──▶│ 운영을 자동화하고   │
  │ 하나의 기계로 이해   │    │ AI 서비스를 운영     │    │ 통합 프로젝트로 완성 │
  │ WSC 이론 + 타이쿤   │    │ kt66 NOC + 모델운영 │    │ 에이전트 + 캡스톤    │
  │ + LLM 워크로드 이해  │    │ + 시나리오 콘솔      │    │ (시설 장애 중심)     │
  └──────────────────┘    └──────────────────┘    └──────────────────┘
        이해한다                  돌린다                 맡기고 책임진다
```

| # | 교과목 | 학점 | 핵심 교보재 | 선수 |
|---|---|---|---|---|
| 1 | AI데이터센터 시스템의 이해 | 3 | 데이터센터 강좌 12강 + 타이쿤 + LLM 워크로드 리터러시 | — |
| 2 | AI데이터센터 통합 운영 | 3 | kt66 NOC + 시나리오 콘솔 + kt66 모델 운영 | 1 |
| 3 | AI 운영 자동화와 통합 프로젝트 | 3 | AI 에이전트 강좌 4모듈 + kt66 에이전트 운영 + 통합 캡스톤 | 1·2 |

## 3. 정규 21학점 버전과의 매핑

| 9학점 과목 | 정규판 대응 | 처리 |
|---|---|---|
| 1. 시스템의 이해 | ① 데이터센터 시스템 + ② LLM(발췌) | ①은 거의 유지, ②는 워크로드 이해 2~3주로 압축 편입 |
| 2. 통합 운영 | ③ 관제 실무 + ④ LLM 서비스 운영 | 두 과목을 전·후반부로 병합(각 ~6~7주) |
| 3. 자동화·통합 | ⑤ 에이전트 자동화 + ⑦ 캡스톤 | 전반 자동화 + 후반 캡스톤(장애 중심, 공방전 제외) |
| (제외) | ⑥ 보안관제 | **타 과목에서 다룸 → 이 버전 제외** |
| (압축) | ② LLM 구축 전체 | 밑바닥 구축 과정은 정규판에서 수강 |
