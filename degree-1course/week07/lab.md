# 7주차 미니 실기 — 미공개 시설 고장 대응 (시험)

> **목표.** 처음 보는 시설 고장 1종에, 5~6주에 배운 트리아지·판단으로 대응한다.
> 정답 문구를 외우는 시험이 아니다 — **절차대로 읽고, 범위를 특정하고, 근거로 판단**하는지를 본다.
>
> **소요.** 40–50분(실기) · **준비물.** 교내망(NOC :8020, 콘솔 :8040), 학생 에이전트.

---

## 준비 — 에이전트 상주 (5~6주와 동일)
```bash
python3 kt66_scenario_agent.py --server http://192.168.12.100:8040 --name "홍길동" --cohort A
```

## 실기 진행
1. **강사가 미공개 고장을 발사**한다(무엇인지 미리 알려 주지 않는다).
2. NOC(:8020)에서 경보·게이지·로그를 읽고, 아래 **트리아지 절차**로 대응한다.
3. 각 단계를 `--report`로 보고하고, 마지막에 `--submit`으로 제출한다.

## 트리아지 절차 (모든 고장에 공통)
| 단계 | 물어야 할 것 |
|---|---|
| ① 인지 | 무슨 경보가 떴나? (경보 이름을 보고) |
| ② 범위/지점 | 영향은 **어디까지**인가? (층 전체? 한 아일? 한 계통?) |
| ③ 원인 국소화 | **무엇이 정상인지**로 좁힌다 (예: "장비는 정상, 그러면 경로다") |
| ④ 조치 | 지금 할 수 있는 완화는? (무엇을 지키고 무엇을 버릴지) |
| ⑤ 통보 | 누구에게 알려야 하나? |

> **함정 주의(6주차 교훈).** "지표가 정상이니 문제 없다/관망한다"는 대개 오답이다.
> 경보가 떴는데 증상이 없다면, **무엇이 조용히 줄고 있는지**(여유·버퍼)를 먼저 의심하라.
> 그리고 범위를 **정확히** 잡아라 — 넓으면 과잉 대응(금지), 좁으면 옆을 놓친다.

## SLA
- 이번 실기의 탐지·조치 SLA는 발사 시 화면/브리핑으로 공지된다. **먼저 인지 보고부터** 남겨야
  탐지 SLA가 잡힌다(조치만 하면 탐지 0점).

## 채점
- 자동 채점(부분 점수) + 탐지/조치 SLA + 금지행위 표시. 총 100점.
- 정답을 하나로 강요하지 않는다 — **근거를 남겼는가**를 본다.
- 채점 세부 기준(루브릭)은 시험 후 [answers.md](answers.md)로 공개한다.
