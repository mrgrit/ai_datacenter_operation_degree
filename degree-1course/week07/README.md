## 이번 주 한눈에
- **복습:** kW·PUE·원 / 경로 병목 / AI 워크로드·액랭 / 사용률 / NOC·트리아지 / 판단·차단.
- **세 원칙:** ① 경로로 본다 ② 여유로 본다 ③ 근거로 판단한다.
- **평가:** 개념 퀴즈 40% · 미니 실기 50% · 판단·태도 10%.

## 검증 상태 (미니 실기, 라이브)
```
ENV-AIR-01(냉방 정상인데 랙 상단만 뜨겁다): 100.0/100 · 탐지=True 조치=True 금지=0
검증 결과: PASS
```
재현: `INSTRUCTOR_KEY=<강사키> bash lab/verify_week07.sh`

> 실기 시나리오는 학생이 안 배운 신규 고장으로 고른다(기본 ENV-AIR-01: 기류/재순환).
> 다른 미공개 시나리오로 교체 가능 — 스크립트의 시나리오/증거만 바꿔 라이브로 재검증.
