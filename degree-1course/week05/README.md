## 이번 주 한눈에
- **개념:** NOC에서 게이지·경보·로그를 읽고, SLA 두 시계(탐지 5분·조치 15분) 안에 대응한다.
- **트리아지 5단계:** 인지 → 범위 특정 → 원인 국소화 → 조치 → 통보.
- **핵심 통찰:** 냉방은 랙이 아니라 **아일 단위**. 범위를 정확히(A 아일) 잡는 것이 목표.

## 검증 상태 (라이브)
이 주차 실습은 **실제 시나리오 콘솔(:8040) API로 전체 루프를 돌려 검증**했다 —
등록 → 발사 → 학생 증거 제출 → finish 채점.
```
점수: 100.0 / 100.0 · 탐지SLA=True · 조치SLA=True · 금지행위=0건
검증 결과: PASS
```
재현: `INSTRUCTOR_KEY=<강사키> bash lab/verify_week05.sh`
(타이쿤 주차는 Node로 모형을 재현했고, 앱 주차는 이렇게 라이브 API로 검증한다.)
