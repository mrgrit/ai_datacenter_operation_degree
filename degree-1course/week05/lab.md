# 5주차 실습 — NOC 투어와 첫 고장 대응 (ENV-CRAC-01)

> **목표.** kt66 NOC 콘솔을 둘러보고, 강사가 발사한 첫 고장(항온항습기 1대 정지)에
> 트리아지 5단계로 대응한다. 대응의 각 단계를 근거와 함께 기록하면 자동 채점된다.
>
> **소요.** 60–90분 · **준비물.** 교내망 접속(NOC :8020, 시나리오 콘솔 :8040)

---

## 파트 A. NOC 콘솔 투어

### A-0. 접속
- NOC 관제 화면: **http://192.168.12.100:8020/**
- (강사) 시나리오 콘솔: **http://192.168.12.100:8040/**

### A-1. 미션 (탐색)
1. **게이지 읽기.** 상단 HUD에서 전력·PUE·온도·부하를 찾는다. **평시 범위**를 적어 둔다
   (온도 22℃ 근처? PUE 1.3~1.6?).
2. **층 오가기.** 엘리베이터 패널로 1F~4F를 오가며 장비 배치를 본다.
3. **탭 둘러보기.** 전력·존·근무자·경보·로그 탭을 열어 무엇이 있는지 확인한다.
4. **스스로 고장 주입.** 강사 패널(고장 48종)에서 CRAC 계열 고장을 하나 주입해 본다.
   화면(온도·색·경보·로그)이 어떻게 반응하는지 관찰하고, **전체 해제**로 되돌린다.

### A-2. 관찰 기록 (제출물 1)
| 항목 | 값/메모 |
|---|---|
| 평시 게이지(온도·PUE·부하) | |
| CRAC 고장 주입 시 바뀐 것(온도·경보·로그) | |
| 경보 탭에 뜬 경보 이름/등급 | |

## 파트 B. 첫 고장 대응 — ENV-CRAC-01 (채점 실습)

### B-1. 상황
2F A 아일의 **항온항습기(CRAC) A가 정지**했다는 경보가 뜬다.
- SLA: **탐지 5분 · 조치 15분**
- 목표: 영향 범위를 **아일 단위**로 정확히 특정하는 것.

### B-2. 트리아지 5단계 — 각 단계를 근거와 함께 기록
아래 5가지를 관제 화면에서 확인하고, 각각을 **증거로 남긴다**(짧은 한 줄 근거 + 종류).

| # | 할 일 | 기록할 근거(예) | 종류(kind) |
|---|---|---|---|
| ① 인지 | CRAC_DOWN 경보 확인 | "CRAC_DOWN 경보 인지 — 항온항습기 A 정지" | alarm |
| ② 범위 | 2F **A 아일**로 국한 확인 | "영향 범위는 2F A 아일에 국한 — 아일 단위" | observation |
| ③ 원인 | 상류 냉동기 정상, 단독 정지 | "상류 냉동기 정상, crac-01 단독 정지로 국소화" | note |
| ④ 조치 | 예비 냉방·기류 정리 | "A 아일 예비 CRAC 가동 + 블랭킹 패널 정리" | action |
| ⑤ 통보 | 시설 담당에 보고 | "시설 담당에 통보·보고 완료" | note |

> **하지 말 것(금지 행위).** "2F 전체 부하 차단" 같은 과잉 대응. 멀쩡한 B·C 아일까지
> 죽인다. 점수를 깎진 않지만 강사가 따로 본다.

### B-3. 채점
5단계를 제대로 남기고 SLA(탐지 5분·조치 15분)를 지키면 **100점**이다.
배점: 인지 20 · 범위 30 · 원인 20 · 조치 20 · 통보 10.

## 검증 상태 (강사/조교 기록)
이 실습은 **실제 시나리오 콘솔(:8040) API로 전체 루프를 돌려 검증**했다 —
등록 → 발사 → 증거 제출(위 5건) → finish(채점).

```
점수: 100.0 / 100.0 · 탐지SLA=True · 조치SLA=True · 금지행위=0건
  - crac-detect  20/20 ✓  학생 인지 보고 — CRAC_DOWN
  - crac-scope   30/30 ✓  '아일' — A 아일에 국한
  - crac-plant   20/20 ✓  '냉동기 정상' — 단독 정지 국소화
  - crac-action  20/20 ✓  action 증거 1건
  - crac-notify  10/10 ✓  '시설' — 통보·보고
검증 결과: PASS (만점 100/100 · SLA 준수 · 금지행위 0)
```

- 검증 스크립트: [`lab/verify_week05.sh`](lab/verify_week05.sh) (강사 키 필요)
- 재현: `INSTRUCTOR_KEY=<강사키> bash lab/verify_week05.sh`
- 위 5건의 증거가 곧 이 실습의 **정답 예시**다(표현은 달라도 근거만 맞으면 인정).
