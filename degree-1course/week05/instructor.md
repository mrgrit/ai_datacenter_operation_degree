## 사전 준비 (수업 전 10분)
1. **앱 생존 확인**
   ```bash
   curl -s http://192.168.12.100:8040/health   # {"ok":true,...}
   curl -s http://192.168.12.100:8020/          # NOC 200
   ```
2. **강사 키 확보**: 시나리오 콘솔 상단 "강사 키" 칸에 넣을 `INSTRUCTOR_KEY`를 준비.
3. **레퍼런스 검증**(권장): 발사→채점 루프가 정상인지 한 번 돌려 본다.
   ```bash
   INSTRUCTOR_KEY=<강사키> bash degree-1course/week05/lab/verify_week05.sh
   # → PASS (100/100). 검증용 학생 zz-검증봇이 콘솔에 남는다(수업 전 무시/정리).
   ```
4. **대상(audience) 결정**: 전체/분반(cohort)/특정 학생. 분반 수업이면 학생에게 `--cohort` 값을 미리 공지.

## 학생에게 시스템 쓰게 하기 (그대로 불러주기)

### ① 최초 1회 — 에이전트 등록(상주 실행)
"각자 랩에서 아래를 실행해라. 이 창은 **켜 둔 채** 둔다(상주하며 폴링한다)."
```bash
python3 kt66_scenario_agent.py --server http://192.168.12.100:8040 --name "홍길동" --cohort A
```
- 최초 실행 시 토큰을 받아 `~/.kt66s_agent.json`에 저장한다. 이후 인자 없이 재실행 가능.
- 발사가 오면 이 에이전트가 **학생 NOC에 고장을 자동 주입**하고 경보를 자동 수집한다.

### ② 강사가 발사 (시나리오 콘솔 :8040)
1. 상단에 **강사 키** 입력.
2. **발사 탭** → 시나리오 검색 `ENV-CRAC-01` 선택 → 대상(전체/분반 A/특정 학생) → **발사**.

### ③ 학생 대응 — 트리아지 5단계를 '보고'로 남긴다 (다른 터미널)
"NOC에서 확인한 것을 **한 줄씩 보고**해라. 이것이 채점 대상이다."
```bash
python3 kt66_scenario_agent.py --report "CRAC_DOWN 경보 인지 — 항온항습기 A 정지" --kind alarm
python3 kt66_scenario_agent.py --report "영향 범위는 2F A 아일에 국한 — 아일 단위" --kind observation
python3 kt66_scenario_agent.py --report "상류 냉동기 정상, crac-01 단독 정지로 국소화" --kind note
python3 kt66_scenario_agent.py --report "A 아일 예비 CRAC 가동 + 블랭킹 패널 정리" --kind action
python3 kt66_scenario_agent.py --report "시설 담당에 통보·보고 완료" --kind note
```
### ④ 제출 → 즉시 채점 결과 확인
```bash
python3 kt66_scenario_agent.py --submit    # → 100/100, 체크별 통과 여부 출력
```

## 강사 시연 포인트
- **경보 뜨는 것 ≠ 성취**: 채점은 학생이 **보고한 증거(source=student)**만 본다. "에이전트가
  자동 수집한 경보"는 맥락일 뿐. 그래서 학생이 `--report`로 판단을 남겨야 점수가 된다.
- **범위(30점)가 가장 무겁다**: 냉방은 아일 단위. "2F 전체 차단"은 금지행위로 표시된다(채점 탭에서 보여 주기).

## 자주 막히는 곳 & 대응
- **학생이 채점 탭에 안 보인다** → 에이전트 등록(`--name`)을 안 했거나 `--server`가 틀림.
- **"진행 중인 시나리오가 없다"** → 발사 전이거나 대상(audience) 불일치(분반/이름 확인).
- **점수 0점인데 대응은 했다** → `--report` 없이 조치만 함. 판단을 **보고**로 남겨야 채점됨.
- **탐지 SLA 실패** → 발사 후 5분 내 첫 보고가 없었음. "먼저 인지 보고부터"를 강조.
- **발사 대상 실수(전체로 나감)** → 콘솔 진행 탭 또는 `POST /api/cancel?batch=<배치>`(강사 키)로 취소.

## 채점·피드백 포인트
- NOC 관찰 30 · 자동 채점(100점) 50 · 판단 기록 20.
- **채점 탭**에서 학생별로: 점수, 탐지/조치 SLA, **금지행위 표시**를 함께 리뷰.
- 부분 점수를 활용해 "어디서 갈렸는지" 개별 피드백(범위를 넓게? 통보 누락?).

## 정리 (수업 후)
- 발사 이력이 남는다. 검증/데모용 학생은 이름으로 구분(예: `zz-검증봇`).
- 콘솔 DB 정리가 필요하면 관리자 권한으로 해당 student 행 삭제(운영자와 협의).
