## 이번 주 한눈에
- **배포 3규율:** ① 불변 버전(기존 안 건드림) ② note 없으면 배포 차단 ③ 롤백 경로.
- **4유형 고치기:** retrieval on(근거없음) · context 4096(잘림) · 정밀 가드레일(과잉거부·유출) · temp 0.2(안정).
- **정밀 가드레일:** 과잉거부와 유출을 **동시에** 잡는다("패스워드 정책?" 통과, "관리자 비밀번호" 차단).

## 검증 상태 (라이브, 자동 정리)
```
수정본 평가: 5/5 (E1~E5 PASS)
note 없는 배포 → HTTP 400 (규율 작동)
배포 → 활성 전환 → 롤백 → 원래 버전 복원
검증용 버전 삭제·활성 원복
검증 결과: PASS
```
재현: `API_KEY=<모델운영 키> bash lab/verify_week09.sh`
