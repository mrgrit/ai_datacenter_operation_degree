# 1주차 실습 — 첫 운영과 세 숫자 (kW · PUE · 원)

> **목표.** 데이터센터 타이쿤을 처음 운영하며 kW·PUE·원을 눈으로 읽고, 냉각 선택과
> 바깥 기온이 요금을 어떻게 바꾸는지 손으로 계산한 뒤 **게임의 실제 물리 모형으로
> 검증**한다. 코딩은 필요 없다. 계산은 검증 스크립트가 자동으로 채점한다.
>
> **소요.** 60–90분 · **준비물.** 웹 브라우저, (검증용) Node.js

---

## 파트 A. 타이쿤 첫 운영 — 화면의 숫자를 읽는다

### A-0. 실행
브라우저에서 아래를 연다(설치·로그인 불필요).
- 플레이: **https://mrgrit.github.io/data_center_tycoon/**
- 체험 모드(장비·계약이 깔린 상태로 시작): **https://mrgrit.github.io/data_center_tycoon/?demo=1**

처음이라면 **체험 모드**로 시작하기를 권한다. 조작은 넷뿐이다 —
클릭=설치 · 우클릭=철거 · 휠=확대 · Shift+드래그=이동 · Space=일시정지.

### A-1. 미션 (관찰만 — 아직 크게 짓지 않는다)
1. 화면 상단(또는 손익/상태 패널)에서 다음 네 숫자를 찾아 적는다:
   **IT 부하(kW) · 총 수요(kW) · PUE · 현재 현금(원).**
2. 계약을 하나 받는다(제안 목록에서 웹 호스팅 같은 작은 것). 받은 뒤 **IT 부하가
   올라가는지** 확인한다.
3. 잠시(게임 내 며칠) 돌린 뒤 **방 온도**와 **PUE**가 어떻게 움직이는지 본다.
   부하가 오르면 열이 오르고, 냉각이 돌면 PUE가 나타난다.

### A-2. 관찰 기록 (제출물 1)
아래 표를 채운다. 정확한 값보다 **"부하를 올리니 무엇이 따라 움직였나"** 를 관찰하는 것이
핵심이다.

| 시점 | IT 부하(kW) | 총 수요(kW) | PUE | 방 온도(℃) | 현금(원) |
|---|---|---|---|---|---|
| 계약 받기 전 | | | | | |
| 계약 받은 직후 | | | | | |
| 며칠 운영 후 | | | | | |

**한 줄 소감:** 부하(kW)를 올렸을 때 어떤 숫자들이 함께 움직였는가?

## 파트 B. 세 숫자 계산 — 그리고 자동 검증

여기서는 게임이 내부에서 쓰는 **실제 공식**으로 다섯 문제를 푼다. 손으로 먼저 어림하고,
검증 스크립트로 정답을 확인한다. (스크립트는 타이쿤의 실제 `catalog.js`·`sim.js`를 그대로
불러와 계산하므로, 게임 화면의 값과 같다.)

### B-1. 다섯 문제 (손으로 먼저 답해 보기)
전기요금 = **165 원/kWh**, 한 달 = **720시간**, 목표 실내온도 = **22℃**.

1. **전기요금의 하한.** IT 1kW를 한 달 켜 두면 전기요금은? 그리고 PUE가 1.5면?
2. **표준 랙 10kW + CRAC(COP 3.0), 바깥 15℃.** 냉각이 쓰는 전기(kW)와 PUE는?
3. **같은 10kW를 인로우(COP 4.2)로 바꾸면?** PUE는? CRAC 대비 월 전기요금은 얼마 아끼나?
4. **한여름 35℃.** 같은 CRAC의 실제 COP는 얼마로 떨어지고, PUE는 얼마까지 오르나?
5. **전력 경로.** 수전 200kW·변압기 250kW면 실제 상한은? 그게 받쳐 줄 IT 부하는 대략?

> 힌트: 2번은 "냉각 전기 = 뺄 열 ÷ COP"에서 출발한다. 뺄 열은 IT 부하(10kW)를 조금 웃도는
> 값이고, 총 수요 = IT + 냉각 + 약간의 손실이다. 정확한 값은 검증 스크립트가 알려 준다.

### B-2. 자동 검증 실행
`lab/` 폴더에서 아래를 실행한다.

```bash
cd degree-1course/week01/lab
node verify_week01.mjs
```

기대 출력(핵심 줄):

```
[문제 1] 전기요금의 하한 (손계산)
  OK  IT 1kW × 720h × 165원: 118800  (기대 118800)
  OK  여기에 PUE 1.5 를 곱하면(냉각·손실 포함): 178200  (기대 178200)

[문제 2] 표준 랙 10kW + CRAC, 바깥 15℃ (게임의 실제 모형)
  OK  냉각이 쓰는 전기(kW): 4.5333
  OK  총 수요(kW) = IT + 냉각 + 손실: 15.1240
  OK  PUE = 총수요 / IT: 1.5124

[문제 3] 같은 10kW 를 인로우 냉각(COP 4.2)으로
  OK  PUE: 1.3718
   → 월 전기요금 ≈ 1,629,681원. CRAC 대비 매달 167,050원 절약

[문제 4] 한여름 35℃ — 같은 표준 랙 10kW + CRAC
  OK  35℃ 의 실제 COP (더울수록 떨어진다): 1.9200
  OK  여름 PUE: 1.7725

[문제 5] 전력 경로
  OK  그 상한이 받쳐 줄 수 있는 IT 부하(kW): 137.9310

검증 결과: 16/16 통과
```

`16/16 통과`가 나오면 성공이다. 이 스크립트는 **강사·조교가 이미 실행해 검증을
마쳤다**(아래 "검증 상태" 참조). 학생은 자기 손계산이 이 숫자와 맞는지 대조하면 된다.

### B-3. 제출물 2 — 한 문장 판단
문제 3의 결과를 근거로, 다음에 답한다.
> **"인로우가 CRAC보다 초기 구매비는 비싸다(3,800만 vs 3,000만원). 그런데도 인로우를
> 고르는 것이 언제 이득인가? 반대로 CRAC이 나은 경우는?"** (정답은 하나가 아니다 —
> 무엇을 근거로 삼았는지 쓰면 된다.)
