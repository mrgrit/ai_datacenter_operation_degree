## 이번 주 한눈에
- **개념:** 현대의 컴퓨터는 건물 한 채(WSC)다. 운영자는 매일 **kW·PUE·원**을 읽는다.
- **핵심 원리:** 모든 전기는 결국 열이 된다 → 부하를 올리면 전기가 두 번 든다.
- **실습:** 타이쿤으로 첫 계약을 받아 세 숫자가 한 고리로 움직이는 것을 관찰하고,
  CRAC vs 인로우 / 겨울 vs 여름의 PUE·요금을 계산해 **자동 검증**한다.

## 검증 상태
```bash
cd degree-1course/week01/lab && node verify_week01.mjs   # → 16/16 통과 (Node v20)
```
교안·실습·정답의 모든 수치는 위 스크립트로 재현·검증되었다.

## 실습에서 검증된 핵심 수치
| 항목 | 값 |
|---|---|
| IT 1kW 월 전기요금 | 118,800원 (PUE 1.5면 178,200원) |
| 표준 랙 10kW + CRAC(15℃) | PUE 1.51, 냉각 4.53kW |
| 표준 랙 10kW + 인로우 | PUE 1.37, CRAC 대비 월 167,050원 절약 |
| 같은 CRAC, 여름 35℃ | COP 3.0→1.92, PUE 1.77 |
| 수전 200·변압기 250 | 실제 상한 200kW → IT 약 138kW |
