# 1주차 실습 정답·해설

> 아래 모든 수치는 [`lab/verify_week01.mjs`](lab/verify_week01.mjs)로 재현·검증했다
> (데이터센터 타이쿤 실제 모형 `catalog.js`·`sim.js` 사용, **16/16 통과**).

## 파트 A — 관찰 (정답 없음, 확인 포인트)
- 계약을 받으면 **IT 부하(kW)가 계약 요구량만큼 오른다.**
- 부하가 오르면 **열이 오르고**, 냉각이 돌기 시작하면 **총 수요(kW)와 PUE가 나타난다.**
- 방 온도는 "IT가 낸 열 − 냉각이 뺀 열"의 균형으로 움직인다. 냉각이 충분하면 22℃ 근처를
  유지하고, 모자라면 오른다.
- 핵심 관찰: **kW를 올렸더니 총 수요·온도·(전기)비용이 함께 움직였다** — 세 숫자가 한
  고리로 묶여 있다는 것.

## 파트 B — 계산 정답

**문제 1. 전기요금의 하한**
- IT 1kW × 720h × 165원 = **118,800원/월**
- × PUE 1.5 = **178,200원/월**
- 뜻: 계약 단가가 kW당 월 17.8만원보다 낮으면 켜 둘수록 손해. (타이쿤의 계약 단가가
  kW당 월 33~78만원인 이유 — 이 하한 위에 있어야 게임이 성립한다.)

**문제 2. 표준 랙 10kW + CRAC(COP 3.0), 15℃**
- 실제 COP = 3.0 (15℃는 카탈로그값 그대로. 15℃를 넘으면 떨어지기 시작)
- 냉각이 쓰는 전기 = **4.53kW** ( ≈ 뺄 열 10.8kW ÷ 3.0 + 상시 소비 )
- 총 수요 = IT 10 + 냉각 4.53 + 손실 ≈ **15.12kW**
- **PUE = 15.12 ÷ 10 = 1.51**
- 월 전기요금 ≈ **1,796,731원** (이 방 하나, 10kW IT 기준)

**문제 3. 같은 10kW를 인로우(COP 4.2)로**
- 냉각 전기 = **3.15kW**, 총 수요 = **13.72kW**, **PUE = 1.37**
- 월 전기요금 ≈ **1,629,681원**
- CRAC 대비 **매달 167,050원 절약**. 장비 하나 바꿨을 뿐인데 PUE 1.51 → 1.37.

**문제 4. 한여름 35℃, 같은 CRAC**
- 실제 COP = 3.0 × (1 − (35−15)×0.018) = **1.92** (더울수록 하락)
- 냉각 전기 = **7.08kW** (겨울 4.53 → 여름 7.08), **PUE = 1.77**
- "여름에 요금이 튄다"의 정체: 같은 방·같은 부하인데 COP가 떨어져 냉각 전기가 커진다.

**문제 5. 전력 경로**
- 실제 상한 = min(수전 200, 변압기 250) = **200kW**
- 받쳐 줄 IT 부하 ≈ 200 ÷ 1.45 ≈ **138kW** (1.45 = IT 1kW가 데려오는 냉각·손실 포함 총수요 어림)
- 뜻: 변압기를 키워도 수전이 200이면 IT는 약 138kW에서 막힌다 — **경로의 최소 지점이 상한.**

## 파트 B 판단 문제 (예시 답 — 정답은 하나가 아님)
- **인로우가 이득인 경우:** 부하가 크고 오래 켜 둘 계약이라 전기요금 절감액이 초기
  차액(800만원)을 빠르게 회수할 때. 위 예에서 월 16.7만원 절약이면 단순 회수에 약
  48개월이지만, 부하가 크고 여름 COP 하락까지 겹치면 회수는 더 빨라진다. 또 열원에
  가까워 고밀도 랙에서 유리.
- **CRAC이 나은 경우:** 부하가 작고 계약이 짧아 절감액이 작을 때, 또는 단순·튼튼함과
  낮은 초기비가 중요할 때. "여유를 싸게 확보"가 목적이면 CRAC.
- 채점 포인트: **회수 기간·부하 크기·계약 길이·여름 요금** 중 무엇을 근거로 삼았는가.
