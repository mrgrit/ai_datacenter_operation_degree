## 이번 주 한눈에
- **개념:** 월 전기요금 = IT × **PUE** × 165 × 720. 고정비(opex)는 부하와 무관.
- **핵심 문장:** "용량을 깔았으면 채워야 한다 — **사용률이 흑자를 만든다.**"
- **반전:** 같은 시설·같은 고정비인데, 25% 채우면 적자·100% 채우면 흑자.

## 실습에서 검증된 핵심 수치
| 항목 | 값 |
|---|---|
| 표준 방(IT 10kW, PUE 1.51) 월 전기 | 약 180만원 |
| 인수 시설 월 고정비 | 205만원 (계약 0건이어도) |
| 사용률 25%(10kW) 영업손익 | **−46만원 (적자)** |
| 사용률 100%(40kW) 영업손익 | **+499만원 (흑자)** |
| 여름(35℃) 월 전기 / 겨울 대비 | 211만원 / +31만원 |
| 위약금 상한 | 월 매출 × 1.2 (10kW → 420만원) |
