# 4주차 실습 — 손익표 읽기 (비용·에너지·사용률)

> **목표.** 타이쿤 손익표에서 매출·전기·고정비·위약금을 갈라 읽고, 사용률을 올렸을 때
> 적자가 흑자로 도는 지점을 찾는다. 여름 요금과 위약금 상한도 계산·검증한다.
> 이해 구간(1~4주)의 마무리 실습.
>
> **소요.** 60–90분 · **준비물.** 웹 브라우저, (검증용) Node.js

## 파트 A. 타이쿤 — 손익표를 읽는다

### A-0. 실행
- 플레이: **https://mrgrit.github.io/data_center_tycoon/**

### A-1. 미션
1. **손익 탭을 연다.** 매출·전기요금·고정비(opex)·사고 대응비·위약금·투자가 각각
   얼마인지 확인한다. 계약이 적을 때 **영업손익이 적자인지** 본다.
2. **사용률을 올린다.** 공랭 계약을 더 받아 랙을 채운다(자리 40kW를 향해). 매출이 오르면서
   **영업손익이 흑자로 도는 지점**을 찾는다.
3. **고정비는 그대로.** 계약을 늘려도 설비·장비 opex(고정비)는 거의 그대로임을 확인한다.
   달라지는 건 매출과 전기요금.
4. **여름을 지난다(관찰).** 게임을 돌려 여름에 접어들 때 **PUE와 전기요금이 오르는지**
   본다(폭염 이벤트가 있으면 더 뚜렷).
5. **순자산 vs 현금.** 증설(Capex)로 현금은 줄어도 순자산·월 손익은 어떻게 움직이는지 본다.

### A-2. 관찰 기록 (제출물 1)
| 항목 | 값/메모 |
|---|---|
| 계약이 적을 때 월 영업손익 | |
| 랙을 채운 뒤 월 영업손익 | |
| 흑자로 돌아선 대략의 사용률/부하 | |
| 여름에 오른 PUE와 전기요금 변화 | |

## 파트 B. 계산 — 그리고 자동 검증

### B-1. 다섯 문제 (손으로 먼저)
전기요금 165원/kWh, 한 달 720시간.
1. **전기요금.** IT 10kW·PUE 1.51인 방의 월 전기요금은? (식: IT × PUE × 165 × 720)
2. **고정비.** 인수 시설(수전·변압기·UPS·냉동기 각 1 + 표준랙 4 + CRAC 2)의 월 고정비 합계는?
3. **사용률.** web 단가 350,000원/kW·월일 때, 인수 시설에 10kW만 채웠을 때와 40kW를
   채웠을 때의 월 영업손익(매출−전기−고정비)은 각각 흑자인가 적자인가?
4. **여름.** 같은 방을 15℃와 35℃에 뒀을 때 월 전기요금 차이는 대략?
5. **위약금.** 10kW·단가 350,000원 계약의 위약금 상한은?

### B-2. 자동 검증
```bash
cd degree-1course/week04/lab
node verify_week04.mjs
```
기대 출력(핵심):
```
[문제 1] 이 방(IT 10kW) 월 전기요금(원): 1796731  (PUE 1.51)
[문제 2] 인수 시설 월 고정비 합계(원): 2050000
[문제 3] [사용률 25%] 적자 -459,829원 / [사용률 100%] 흑자 +4,989,270원
[문제 4] 여름 월 전기요금 2,105,730 / 겨울 대비 +308,999원
[문제 5] 위약금 상한 4,200,000원 (= 월 매출 ×1.2)
검증 결과: 14/14 통과
```
`14/14 통과`면 성공. 강사·조교가 이미 실행해 검증을 마쳤다(아래 참조).

> 매달 적자다. 나에게는 두 가지 길이 있다 — ⑴ 계약을 더 받아 채운다, ⑵ 안 쓰는 장비를
