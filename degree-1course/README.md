# AI데이터센터운영 — 1과목 맛보기 개론

> **"한 학기에 AI데이터센터 운영의 전 과정을 한 바퀴 돌려 본다."**
>
> 21학점 정규판·9학점 집중판의 내용을 **한 과목(3학점)으로 압축한 개론**이다.
> 시스템 이해 → 시설 관제 → AI 서비스 운영 → 운영 자동화를 각각 짧게 **체험**하고,
> 마지막에 미니 통합 훈련으로 묶는다. 보안은 제외한다(학과 타 과목에서 다룸).

---

## 1. 이 과목의 성격

- **맛보기(survey).** 각 영역을 깊게 파지 않는다. "AI데이터센터를 운영한다는 것이
  무엇인지"를 손으로 한 번씩 겪어 보고 전체 지도를 얻는 것이 목표다.
- **누구에게.** 전공 입문·교양·타 전공생, 또는 정규/집중 디그리를 시작하기 전
  전체를 조망하려는 학생. 이 한 과목이 심화 과정의 **관문(gateway)** 역할을 한다.
- **하나의 세계관.** 정규판과 같은 가상기업 kt66의 데이터센터를 무대로,
  같은 실습 도구(타이쿤·NOC·모델 운영·에이전트 운영)를 맛본다.
- **보안 제외.** 시설 장애로부터 가용성을 지키는 '운영'에 집중한다.

```

 이해         체험 ①         체험 ②          체험 ③          통합
┌────────┐  ┌────────┐   ┌────────┐    ┌────────┐    ┌────────┐
│건물+워크 │─▶│시설 관제 │──▶│AI 서비스 │───▶│운영     │───▶│미니     │
│로드 이해 │  │(NOC)    │   │운영     │    │자동화   │    │캡스톤   │
│WSC+타이쿤│  │고장 대응 │   │(모델운영)│    │(에이전트)│    │+발표    │
└────────┘  └────────┘   └────────┘    └────────┘    └────────┘
```
