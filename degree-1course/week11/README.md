## 이번 주 한눈에
- **신설 6요소:** id·층/존·**팀(필수)**·런타임·모델·**자율성**.
- **자율성은 낮게 시작:** 새 근무자는 L1(보고 전용) → 신뢰 쌓이면 L2로 승격.
- **팀 필수:** 팀 없는 근무자는 거부(책임의 공백 방지).
- **렌더해야 적용 / 항상 되돌리기 경로**(백업·삭제로 원복).

## 검증 상태 (라이브, 자동 정리)
```
신설: 9 → 10명 · 자율성=L1
렌더 ok=True
삭제: → 9명 (원복) · 잔재 0
팀 없이 신설 → 거부(조직 정합성) 확인
검증 결과: PASS (조직 완전 복원)
```
재현: `API_KEY=<에이전트 운영 키> bash lab/verify_week11.sh`
