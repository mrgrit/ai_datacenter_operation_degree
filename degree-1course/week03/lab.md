# 3주차 실습 — AI로 가는 길 (GPU·액랭·평판)

> **목표.** AI 워크로드가 시설에 요구하는 것을 타이쿤으로 겪는다 — GPU 랙은 액랭(CDU)이
> 먼저 있어야 지어지고, AI 계약은 액랭 랙과 평판이라는 두 문턱을 넘어야 온다. 액랭이
> 오히려 PUE를 낮추는 것을 계산·검증한다.
>
> **소요.** 60–90분 · **준비물.** 웹 브라우저, (검증용) Node.js

---

## 파트 A. 타이쿤 — AI 데이터센터로 가는 길

### A-0. 실행
- 플레이: **https://mrgrit.github.io/data_center_tycoon/**

### A-1. 미션
1. **GPU 랙을 바로 지어 본다.** 빈 칸에 GPU 랙을 설치하려 하면 **"같은 층에 CDU가 먼저
   있어야 한다"** 며 막히는 걸 확인한다.
2. **순서를 지킨다.** 같은 층에 **CDU를 먼저** 설치한 뒤 GPU 랙을 설치해 본다(이번엔 됨).
3. **AI 계약이 보이나?** 제안 목록을 확인한다. 시작 평판(20)에선 **AI 계약이 안 보인다**
   (웹·DB 위주). 왜인지 생각해 본다.
4. **평판을 올린다(관찰).** 작은 공랭 계약을 안정적으로 운영하면 월간 평가로 평판이
   오른다. 평판이 55를 넘으면 AI 추론 계약이 제안에 뜨는지 지켜본다.
5. **PUE 비교.** GPU 방(액랭)의 PUE와 공랭 방의 PUE를 비교해 본다. 어느 쪽이 낮은가?

## 파트 B. 계산 — 그리고 자동 검증

### B-1. 다섯 문제 (손으로 먼저)
1. **전력밀도.** GPU 랙(50kW)은 표준 랙(10kW)의 몇 배 밀도인가?
2. **설치 제약.** GPU 랙을 지으려면 같은 층에 무엇이 먼저 있어야 하나?
3. **계약 배치.** AI 추론 계약(needs: liquid)을 공랭 랙만 있는 층에 배치하면 어떻게 되나?
4. **평판 게이트.** AI 추론·AI 학습의 최소 평판은? 시작 평판(20)에서 제안 풀에는 어떤
   계약들이 뜨나?
5. **액랭 PUE.** GPU 랙 50kW를 CDU(COP 8.0)로 식히면 냉각 전기(kW)와 PUE는? 같은 열을
   공랭(COP 3.0)으로 빼면 냉각 전기는?

### B-2. 자동 검증
```bash
cd degree-1course/week03/lab
node verify_week03.mjs
```
기대 출력(핵심):
```
[문제 1] ... GPU 랙은 표준 랙의 몇 배 밀도: 5
[문제 2] ... CDU 없이 GPU 랙 설치 → 거절 / CDU 설치 후 → 성공
[문제 3] ... 공랭 랙뿐인 층에 AI(액랭) 배치 → 실패
[문제 4] ... 시작 평판(20)에서 AI 추론 포함?: false  (풀 = [web, db])
[문제 5] ... CDU COP 8 / 냉각 8.06kW / PUE 1.21 / (공랭이면) 18kW
검증 결과: 22/22 통과
```
`22/22 통과`면 성공. 강사·조교가 이미 실행해 검증을 마쳤다(아래 참조).
