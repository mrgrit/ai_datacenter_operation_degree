## 이번 주 한눈에
- **개념:** 전기는 수전→변압기→UPS→랙을 지난다. 열은 랙→CRAC→냉동기로 빠진다.
  각 경로에 용량·부하·여유가 따로 있고, **가장 먼저 여유가 0이 되는 지점**이 병목.
- **핵심 문장:** "랙에 자리가 있다고 받는 게 아니다. 열을 뺄 수 있어야 받는 것이다."
- **실습:** 인수한 시설(랙 40kW·제열 80kW·수전 200·UPS 150)을 파악하고, 자리의 벽·제열의
  벽을 만난 뒤 병목을 골라 증설한다.

## 검증 상태
```bash
cd degree-1course/week02/lab && node verify_week02.mjs   # → 29/29 통과 (Node v20)
```
교안·실습·정답의 모든 수치는 위 스크립트로 재현·검증되었다.
(작성 중 3층 개설 비용 오기를 검증이 잡아냈고 실제값으로 정정 — 2층 180M / 3층 320M.)

## 실습에서 검증된 핵심 수치
| 항목 | 값 |
|---|---|
| 인수 시설 | 표준 랙 40kW 자리 · CRAC 제열 80kW · 시작 현금 12억 |
| 전력 용량 | 수전 200 · 변압기 250 · UPS 150 · 냉동기 250 (kW) |
| IT 부하 상한 | 약 136kW — **병목은 UPS**(150÷1.1) |
| 자리의 벽 | 40kW 뒤 30kW 추가 → 배치 실패 |
| 제열의 벽 | 자리 100kW + 제열 80kW → 여유 −20kW |
| 증설 비용 | 수전 +200kW 4천만 · 냉동기 +250kW 9천만 · 2층 1.8억 |
