# 12주차 실습 — 판단 비교 워크숍

> **목표.** 시스템을 조작하는 대신, 지금까지 내가 내린 판단들을 하나의 틀로 다시 쓰고
> 서로 비교한다. "무엇을 지키고 그 대가가 무엇인가"를 세 영역에 걸쳐 관통시킨다.
>
> **소요.** 90분 · **준비물.** 5~11주에 남긴 **내 판단 기록**(각 실습의 제출물).

---

## 파트 A. 내 판단 3개 모으기
5~11주에서 세 영역 각 1개씩, 내가 판단을 내렸던 순간을 가져온다.
- **시설 관제**(5~6주): 예) UPS 절체·부하 차단·아일 범위·냉각탑 학습 중단.
- **서비스 운영**(8~9주): 예) 가드레일 조이기, 컨텍스트 늘리기, 배포/롤백.
- **운영 자동화**(10~11주): 예) 근무자 자율성 L1/L2 선택.

## 파트 B. 공통 틀로 다시 쓰기 (제출물 1)
세 판단을 아래 표로 정리한다.

| 영역 | 상황 | 지킨 것 | 버린 것(대가) | 근거 | 우선순위 어디에? |
|---|---|---|---|---|---|
| 시설 | | | | | |
| 서비스 | | | | | |
| 자동화 | | | | | |

> 마지막 칸("우선순위 어디에?")은 kt66 우선순위 —
> ① 사람 안전 ② 되돌릴 수 없는 손실 ③ 서비스 연속성 ④ 효율·비용 — 중 어디에 걸리는지 적는다.

## 파트 C. 조별 비교·토론 (제출물 2)
3~4명이 모여 같은/비슷한 상황에 **서로 다른 선택**을 한 사례를 찾는다.
1. 두 선택의 **대가**를 나란히 적는다.
2. "누가 옳은가"가 아니라 **"각자 무엇을 지키려 했는가"** 를 정리한다.
3. 회사 우선순위로 볼 때 어떤 상황에서 어느 선택이 더 맞는지 토론한다.

**토론 산출물(한 단락):** "우리 조는 ___ 상황에서 A는 ___ 을, B는 ___ 을 지켰다.
우선순위 ___ 을 기준으로 보면 ___ 이 더 맞지만, ___ 라는 대가가 있었다."

## 검증 상태 (강사/조교 기록)
- 이 주차는 **시스템 조작이 없는 판단 워크숍**이라, 라이브 채점 대신 세 영역의 **판단 앵커가
  현재도 일관됨**을 읽기 전용으로 확인한다.
- 검증 스크립트: [`lab/verify_week12.sh`](lab/verify_week12.sh) (읽기 전용, 키 불필요)
- **실행 결과: PASS**
  ```
  ① 시설 ENV-CT-01 SLA: 탐지 3분·조치 18분  (버퍼 안에 판단)
  ② 서비스 지표: over_refuse·leak·truncated·ungrounded (가드레일/컨텍스트 트레이드오프)
  ③ 자동화 우선순위: 사람 안전 > 되돌릴 수 없는 손실 > 서비스 연속성 > 효율·비용
  검증 결과: PASS (세 영역의 판단 앵커가 라이브로 일관)
  ```
- 재현: `bash lab/verify_week12.sh`
