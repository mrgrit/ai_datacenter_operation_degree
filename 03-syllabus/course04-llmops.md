| 항목 | 내용 |
|---|---|
| 이수구분 / 학점 | 전공필수 / 3학점 (이론 1 + 실습 2) |

## 교과목 개요
2학기 버전의 질문은 "만들 수 있는가"가 아니라 **"계속 잘 돌게 할 수 있는가"**다.
학생은 사내 LLM 서비스의 운영자가 되어, 수요 생성기가 페르소나별로 만들어 내는
실제형 트래픽을 받고, 지표에서 **아무도 말해 주지 않는 간접 요구**를 읽어내고,
티켓으로 승격된 요구를 manifest(시스템 프롬프트·파라미터)와 knowledge(사내 지식)
수정으로 해결하고, 평가를 통과한 새 버전만 배포한다. 이 과목의 대원칙 세 가지 —
기존 버전을 고치지 말고 새 버전을 만들 것, 이유(note) 없는 배포는 차단될 것,
전부 만점인 설정은 없으므로 **어디를 포기할지 정하는 것이 운영**이라는 것.

## 학습 목표
1. LLM 서비스의 실패 유형(응답 잘림, 근거 없는 답변, 과차단, 미차단)을 트래픽에서 식별할 수 있다.
2. 운영 지표를 읽어 티켓이 오기 전에 간접 요구를 도출할 수 있다.
3. manifest(프롬프트·컨텍스트·가드레일)와 knowledge 문서를 수정해 요구를 해결할 수 있다.
4. 버전 관리 원칙(불변 버전·변경 사유 기록·롤백 경로)을 지켜 변경을 수행할 수 있다.
5. 평가 5개 항목의 상충 관계를 이해하고, 트레이드오프를 명시한 배포 판단을 내릴 수 있다.

## 주차별 계획

| 주 | 주제 (콘솔 단계 매핑) | 실습 |
|---|---|---|
| 1 | LLMOps 개관 — 만드는 일과 돌리는 일의 차이, 서비스로서의 LLM | 콘솔 투어, 활성 버전에 직접 질의("손으로 친 것도 트래픽이다") |
| 2 | [1단계] 트래픽 이해 — 페르소나·수요 생성기·실패의 4유형 | 빨간 줄(실패) 20건 수집·분류 |
| 3 | [2단계] 지표 I — 무엇을 재는가: 품질·지연·비용·안전 | 게이지 판독, 이상 지표 탐지 |
| 4 | [2단계] 지표 II — 간접 요구 읽기: 티켓이 되기 전에 | 지표→가설→검증 질의 사이클 |
| 5 | [3단계] 요구사항 — 임계 초과와 티켓 승격, 손댈 항목 읽기 | 티켓 3건 원인 분석 |
| 6 | [4단계] 수정 I — manifest: 시스템 프롬프트·파라미터 (②과목 프롬프트 기법 재활용) | v2 작성: 프롬프트 수정으로 티켓 해결 |
| 7 | [4단계] 수정 II — knowledge: 검색해 붙이는 사내 지식(RAG 기초) | 근거 없는 답변 티켓을 지식 보강으로 해결 |
| 8 | **중간 실기** — 미공개 티켓 2건을 새 버전으로 해결·배포까지 | |
| 9 | 가드레일 — 풀면 뚫리고 조이면 정상 질문이 막힌다 | 과차단/미차단 균형점 탐색 실험 |
| 10 | [5단계] 평가 I — 평가 항목 설계와 상충 관계 | 같은 버전을 항목별로 재평가·해석 |
| 11 | [5단계] 평가 II — 배포·롤백, note 규율 | 배포 → 버전별 비교("같은 창에서 나란히") |
| 12 | 사고 대응 — 배포 후 악화 감지와 회수 판단 | 강사가 회귀(악화) 버전 주입 → 탐지·롤백 훈련 |
| 13 | 비용·용량 — 토큰 비용, GPU 서빙 용량, 컨텍스트 길이와 지연 (①-8강 연결) | 컨텍스트 확대의 지연 비용 실측 |
| 14 | 종합 운영전 — 1주일치 트래픽·티켓을 팀별 운영 | 운영 인수인계 문서 작성 |
| 15 | **기말 실기** — 티켓 백로그 해소전 + 최종 운영 보고서 (버전 이력·트레이드오프 서술) | |

## 평가
실기(중간 20 + 기말 30: 티켓 해결·지표 개선·배포 규율) / 버전 이력·note 품질 20 /
운영 보고서(트레이드오프 서술) 20 / 평시 실습 10.

## 운영 메모
- ②과목을 안 들은 수강생 유입 대비: 1~2주에 토큰·컨텍스트·미세조정 최소 요약 배포.
- **주차별 이론 교안 부재** — 콘솔 5단계 구조가 목차 초안이다. 지표 정의서와
  실패 유형 해설서 집필이 보강 과제([04](../04-improvement-analysis.md) §2).
- 12주 '회귀 버전 주입'은 강사 시나리오로 추가 개발 필요 (현 콘솔 기능 확장).
